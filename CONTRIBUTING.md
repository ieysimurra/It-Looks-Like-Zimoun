# Contribuindo · Contributing

## 🇧🇷 Português

Contribuições são bem-vindas! Tipos aceitos:

- 🐛 **Bugs** — abra uma Issue com navegador, OS e passos para reproduzir
- 🎵 **Novos materiais** — proposta de síntese para outros materiais físicos
- 🏛️ **Novos espaços acústicos** — IRs sintéticas com outros caracteres
- 🌐 **Traduções** — o painel informativo aceita novos idiomas
- 📱 **Mobile / Safari** — melhorias de compatibilidade

**Fluxo:**
1. Fork → branch `feature/nome` → commit → Pull Request
2. Descreva o que mudou e por quê

**Convenções:**
- Comentários em Português do Brasil
- Sem dependências externas (apenas Web APIs nativas + Google Fonts CDN)
- ES6 Modules — sem bundler, sem transpiler

## 🇺🇸 English

Contributions are welcome! Accepted types:

- 🐛 **Bugs** — open an Issue with browser, OS and reproduction steps
- 🎵 **New materials** — synthesis proposals for other physical materials
- 🏛️ **New acoustic spaces** — synthetic IRs with different characters
- 🌐 **Translations** — the info panel accepts new languages
- 📱 **Mobile / Safari** — compatibility improvements

**Flow:**
1. Fork → branch `feature/name` → commit → Pull Request
2. Describe what changed and why

**Conventions:**
- Comments in Brazilian Portuguese
- No external dependencies (native Web APIs + Google Fonts CDN only)
- ES6 Modules — no bundler, no transpiler
